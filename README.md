# Nico Live Message Recorder

ニコニコ生放送の映像ストリームとコメントを別々に直接保存し、コメント付き動画を生成できるWindowsデスクトップアプリです。

**開発版：0.1.0-beta.29**

## 主な機能

- 左メニューを「ホーム」「配信管理」「コメント・動画」「保存データ」「アプリ」の5カテゴリに整理
- ダッシュボード、配信者監視、放送接続・録画、コメントログ、コメント付き動画生成、録画ライブラリを画面ごとに切り替え

- Kick Live Message Recorderを参考にした日本語ダッシュボード（登録配信者数・LIVE数・録画状態の統計カード）
- 登録配信者のLIVE一覧に配信者名・配信タイトル・開始時刻・リアルタイム経過時間・放送IDを表示
- LIVE一覧から該当するニコニコ視聴ページをワンクリックで開く
- 録画ライブラリから確認ダイアログ付きで動画だけを削除（関連コメントログは保持、録画中ファイルは削除不可）
- テキスト入力欄で右クリックの切り取り・コピー・貼り付け、Ctrl+X / Ctrl+C / Ctrl+V / Ctrl+A に対応
- タイムシフトの映像・音声に過去コメントを取得してJSONLへ保存し、コメント付き動画へ同期
- LIVE一覧の「録画開始」から、その配信の映像・音声とコメントをワンクリックで同時保存（配信者名・ユーザーIDも保存先へ反映）
- 日本語ダッシュボードとアプリ内バージョン表示
- 放送IDまたは視聴URLを入力し、統合パネルから映像・音声の直接録画とコメント取得を同時開始
- コメント取得のみの単独接続にも対応
- 配信者名・ユーザーIDごとに映像とコメントを自動フォルダー分け
- コメント保存形式（JSONL / CSV / ASS / すべて）を選択可能
- 録画中とコメント取得中の状態を別々にリアルタイム表示
- ニコニコ視聴ページを認証済みセッションで別ウィンドウ表示し、録画を続けたままプレビューを閉じる機能
- ニコニコのログイン画面をアプリ内で開く
- 過去コメントとリアルタイムコメントの受信
- コメント、ギフト、エモーション、通知、運営コメントをJSONLへ自動保存
- コメント保存ファイルのCSV書き出し
- コメントJSONLからASS字幕を作成（録画開始時刻に同期）
- NicoConvAssを参考にしたコメント付き動画生成（フォント・最大行数・表示秒数・縁取り・影・NGワード・位置・透明度・色・同期ずれを編集）
- HandBrakeを参考にしたWebM / MP4出力と画質プリセット（MP4は内蔵FFmpegでH.264 / AACへ変換し、失敗時はWebMを残す）
- MP4への変換中もFFmpegの進捗を表示し、一時ファイルは毎回異なる名前で安全に保存
- 出力形式と拡張子が違う場合は保存先を明示して確認し、変更後のファイルが既にある場合は上書き確認を表示
- 出力幅・高さの指定、縦横比維持、fps・ビットレート調整に対応
- Streamlinkのニコ生プラグインを利用した配信ストリームの直接録画
- 最新のStreamlinkとFFmpegをWindowsアプリに同梱し、別途インストール不要
- Streamlinkの公式Windows Portable更新を起動時および6時間ごとに確認し、SHA-256検証後に自動適用
- Streamlink更新の自動適用を設定画面からオン／オフ可能
- 保存フォルダーから録画ライブラリを開き、動画・コメントの検索、種類別絞り込み、再生、保存場所表示、確認付き動画削除
- 録画停止後またはアプリ終了時にTSからMP4へ無劣化変換
- アプリ終了時は録画・コメントログを順番に安全終了し、未完成の合成動画は削除
- 画質（最高・低）の選択
- ユーザーIDを登録して配信開始を監視し、検知直後に映像・音声とコメントを同時に自動録画
- 最短10秒間隔の配信監視、公開放送履歴APIの並列確認、フォロー限定配信の検知に対応
- LIVE検知時と自動録画の開始結果（成功・失敗）をWindows標準通知でお知らせし、通知クリックでアプリを再表示
- Windowsログイン時の自動起動、タスクトレイ常駐、ウィンドウを閉じた後の監視継続に対応
- 監視中はPCのスリープを抑止でき、画面を消灯したまま長時間監視を継続
- アプリ再起動時に現在放送中の番組も再検知し、自動録画を再開
- 監視対象・監視間隔・自動録画・画質・常駐動作を設定画面から管理
- コメント付き動画生成時に、元動画映像を消さずにコメントを重ねる
- GitHub Releasesからβ版の更新を自動確認・ダウンロードし、再起動時に更新

**画面キャプチャによる録画機能は廃止しました。** getDisplayMedia、画面・ウィンドウの選択処理は録画には使用しません。

## Windows通知について

Windows 10 / 11のデスクトップ通知を使用します。設定画面の「配信開始・自動録画の開始結果をWindows通知で知らせる」でオン／オフできます。Windows側の「通知」およびアプリ通知が無効になっている場合、集中モード／応答不可が有効な場合などは通知が表示されないことがあります。インストーラー版ではアプリのスタートメニュー登録を利用します。通知をクリックするとアプリのウィンドウを再表示します。

## 24時間監視について

Windowsログイン時にアプリを自動起動し、監視対象が登録されていれば配信監視を自動開始します。ウィンドウの閉じるボタンはタスクトレイへ最小化され、監視・録画・コメント取得を継続します。PCのスリープ抑止を有効にすると、画面を消灯したまま監視を継続できます。PCの電源断、再起動中、ネットワーク断、ニコニコ側のAPI障害中は検知できません。検知間隔は最短10秒で、API応答時間によって録画開始までの時間は変わります。

## 必要なソフトウェア

**配布するWindowsアプリの利用者は、Streamlink・FFmpeg・Pythonを別途インストールする必要はありません。** いずれもWindowsアプリの中に同梱されます。

ソースコードから起動する場合はNode.js 22以上とWindows PowerShellが必要です。初回は `npm run prepare:streamlink` が公式Portable版を自動取得・検証します。Windows用の配布ビルドでは `npm run dist:win` がこの準備を自動実行します。

## 基本的な使い方

1. アプリ上部の「ニコニコにログイン」からログインします。視聴権限が必要な番組では、視聴可能なアカウントでログインしてください。
2. 放送ID（例：lv123456789）または視聴URLを入力します。
3. 画質を選び「接続して映像・音声＋コメントを録画」を押します。配信映像・音声の直接録画とコメント取得を同時に開始し、同期マーカーを同じコメントログに記録します。録画中に視聴ページを開いておく必要はありません。
4. コメントだけを保存したい場合は「コメントのみ接続」を使えます。コメントのみ接続した後、同じ放送IDでメインの録画ボタンを押して映像・音声録画を追加することもできます。
5. 「録画停止」で映像取得を終了します。コメント取得も止める場合は「切断」を押します。録画停止後、内蔵FFmpegによりMP4へ無劣化変換します。

## 配信者の監視・自動録画

ダッシュボードの「録画したい配信者を監視」で、ニコニコのユーザーIDまたはユーザーページURLを登録できます。監視中に配信を検知すると、LIVE一覧に配信者名・配信タイトル・放送ID・取得できた配信開始時刻・経過時間を表示します。経過時間は画面上で毎秒更新されます。各カードの「録画開始」から、手入力せずに映像・音声とコメントを同時保存できます。すでに別の配信を録画中の場合は、誤って二重開始しないよう操作を無効にします。

1. 「ユーザーID / ユーザーページURL」に数字のユーザーID、または `https://www.nicovideo.jp/user/ユーザーID` を入力します。
2. 必要に応じて表示名を入力し、「監視リストに追加」を押します。
3. 「監視開始」を押すと登録ユーザーの公開放送履歴を確認します。
4. 配信開始を検知すると、設定に応じてコメント取得と映像録画を自動で開始します。

監視間隔は「設定」から最短10秒・15秒・30秒・1分・2分・5分に変更できます。設定画面は「配信監視・自動録画」「コメント保存」「アプリ動作・更新」に分類し、コメント付き動画生成画面の細かな項目も「コメント表示」「文字スタイル」「同期・出力」に整理しています。自動録画の有効／無効、録画画質、アプリ起動時の監視自動開始も設定できます。複数の配信が同時に始まった場合は、現在の録画を中断せず、検知した配信を順番に録画します。視聴権限・通信状態などで自動録画に失敗した場合は、その放送を次回の監視確認で再試行します。

ログイン中は、ニコニコのフォロー中番組一覧APIを先に確認し、登録した配信者の放送が見つからない場合は `isIncludeNonPublic=false` の公開放送履歴APIで補完します。これにより、フォロー中アカウントに表示されるフォロー限定番組も検知できる場合があります。非公開番組を含め、ログイン中アカウントに表示・視聴権限がない配信を取得する機能ではありません。APIはニコニコ側の仕様変更やアクセス制限の影響を受ける可能性があります。

参考にした [nicoLiveCheckTool](https://github.com/guest-nico/nicoLiveCheckTool) と [NicoLiveRecorder](https://github.com/honishi/nico-live-recorder) のように、複数の検知経路を組み合わせる設計を取り入れています。本アプリでは両プロジェクトのソースコードを取り込まず、フォロー中番組APIと公開放送履歴APIを組み合わせた独立実装です。タイムシフトの過去コメント取得には [NdgrClientSharp](https://github.com/TORISOUP/NdgrClientSharp) が公開するNDGRのPrevious / Backward取得方式を参考にしています。

## 設定

画面右上の「設定」から、配信監視・自動録画、コメント保存、Windows起動・常駐、Streamlink自動更新、Windows通知のオン／オフをカテゴリ別に変更できます。通知は既定で有効です。登録した配信者のLIVE検知時に通知し、その後の自動録画開始結果も通知します。コメント取得に失敗して映像録画だけ開始した場合は、その状態を区別して表示します。同じ放送の録画失敗通知は再試行のたびには繰り返さず、再試行が成功したときに成功通知を表示します。コメント付き動画生成の細かな設定は、専用画面で「コメント表示」「文字スタイル」「同期・出力」に分けて編集できます。JSONLはコメント付き動画との同期に使用するため常に保持し、CSV / ASSは追加ファイルとして作成します。設定と監視対象ユーザーはWindowsのユーザーデータ領域へ保存されます。

## 保存場所

既定の保存先はWindowsの「ビデオ」フォルダー内の NicoLiveRecorder です。

- comments：`<配信者名>_<ユーザーID>` ごとのフォルダーにコメント・イベントのJSONLファイル
- videos：`<配信者名>_<ユーザーID>` ごとのフォルダーに直接取得したTSファイル、または変換後のMP4ファイル

配信者名を取得できなかった場合はユーザーIDを含む代替フォルダー名を使います。既存の旧形式フォルダー内の録画ファイルは自動移動しません。「録画ライブラリ」では videos / comments フォルダーを読み取り、配信者名・放送ID・ファイル名で検索できます。動画は既定のプレーヤーで再生し、ファイルの保存場所をエクスプローラーで表示できます。動画の「削除」は確認ダイアログ付きで、録画中・確定中のファイルは削除できません。削除対象は動画ファイルだけで、コメントログは残ります。

JSONLは1イベント1行の同期用マスターデータとして常に保存します。設定でCSV / ASS / 両方を選ぶと、コメント取得を停止したときに追加ファイルを自動作成します。コメント画面の「CSVを書き出す」や「ASSに変換」から個別に出力することもできます。「コメント付き動画を生成」では録画動画とJSONLを選択し、編集項目で文字サイズ・スクロール速度・最大行数・表示秒数・フォント・縁取り・影・NGワード・上下余白・透明度・同期ずれ（±10秒）・表示種類・文字色・出力解像度・fps・ビットレートを調整できます。出力形式はWebMまたはMP4を選べます。MP4は内蔵FFmpegでH.264 / AACに変換し、変換に失敗した場合は生成済みWebMを残します。MP4への変換が有効な環境では、録画開始・停止マーカーを利用してコメントを同期します。ログに ue / shita、色、big / small の指定がある場合は字幕・合成動画にも反映します。

## アプリの自動アップデート

Windowsのインストーラー版（NSIS）では、GitHub Releasesのβ版更新チャンネルを利用します。自動更新の配布にはGitHub Releasesへの公開が必要です。GitHubの **Actions → Release Nico Live Message Recorder → Run workflow** を実行してβ版を公開します。公開されたReleaseに `beta.yml` とWindowsインストーラーが含まれて初めて、アプリ側の更新確認・ダウンロードが動作します。ZIP版は自動更新の対象外です。

- 起動後に更新を確認し、その後は約6時間ごとに再確認します。
- 新しいβ版が公開されている場合はバックグラウンドでダウンロードします。
- ダウンロード完了後、画面の「再起動して更新」を押すと、録画とコメントログを安全に終了してから更新します。
- 更新ファイルはGitHub Releasesから取得し、electron-updaterがSHA-512チェックサムを検証します。

**初回のみ手動更新が必要です。** β7以前には自動アップデート機能が入っていないため、自動更新機能を含むβ版のWindowsインストーラーを一度インストールしてください。以降のβ版はアプリ内から更新できます。ポータブルZIP版は自動更新の対象ではないため、最新版ZIPを手動で入れ替えてください。

### 新しいバージョンの公開

`package.json` のバージョンを更新して `main` に反映すると、Windowsビルドワークフローがテストとインストーラー／ZIP作成を実行します。**mainブランチのビルドとテストが成功すると、Releaseワークフローが自動で起動し、未公開バージョンをGitHub Releasesへ公開します。** 同じバージョンがすでに公開済みなら重複公開しません。

従来どおり `vバージョン` 形式のタグ（例：`v0.1.0-beta.16`）を付けた場合や、GitHubの **Actions → Release Nico Live Message Recorder → Run workflow** から手動実行した場合も公開できます。公開されたβ版は `beta` チャンネルで配信されます。

アプリ内自動更新はWindowsのNSISインストーラー版が対象です。ZIP版は自動更新されないため、Actionsのビルド成果物またはGitHub Releasesから新しいZIPを手動で入れ替えてください。

この公開ワークフローはリポジトリに設定済みの `GITHUB_TOKEN` を使用するため、個人アクセストークンをソースコードへ書き込む必要はありません。

## 直接録画の方式と制限

映像はStreamlinkのニコ生プラグインでHLS配信を取得し、ファイルへ直接書き込みます。同梱版は公式Windows Portable版 Streamlink 8.6.3-1（Python 3.15.2 / x64）です。Windowsビルド時に公式Portable ZIPを取得し、公開SHA-256と照合してから同梱します。展開後は `nicolive.py` の `STREAM_READY_TIMEOUT` と `STREAM_OPENED_TIMEOUT` をそれぞれ30秒へ変更します。接続許可やHLSストリーム開始の応答を標準の6秒より長く待機します。Portable ZIPにはStreamlink・組み込みPython環境・FFmpegが含まれ、ユーザーのPCのPATHやシステム設定は変更しません。Streamlink Windows Portable版に含まれる組み込みPython環境とFFmpegは、配布元が独自にビルドした未署名バイナリです。環境によってはセキュリティソフトが誤検知する可能性があります。

Streamlink実行中のみ、アプリ内ログインで得た user_session を一時設定ファイルに渡します。一時設定は録画プロセス終了後に削除し、Streamlinkのプラグインキャッシュも無効にしています。

Streamlink自動更新はWindows Portable版の公式GitHub Releasesを起動時および6時間ごとに確認します。更新ZIPのSHA-256、実行ファイルのバージョン、FFmpegの起動を検証してからユーザーデータ領域へ新バージョンを展開し、次の録画から使用します。録画中の実行ファイルは上書きしません。設定で自動適用を無効にした場合は、新しい版を見つけたときに画面から手動適用できます。

録画ファイルはまずMPEG-TS（.ts）で保存し、内蔵FFmpegで映像・音声を再エンコードせずMP4へ格納し直します。Streamlinkや配信側の仕様変更、ネットワーク切断、視聴権限、配信形式によって録画できない場合があります。

ログインや視聴権限のない番組、DRM・暗号化などの保護を回避して録画する機能はありません。通常の視聴操作でアクセスできる配信のみを対象にし、利用規約や権利者の許可に従ってください。

## 録画中の映像プレビュー

録画パネルの「映像プレビューを開く」から、入力中の放送ID・視聴URLをニコニコの視聴ページとして別ウィンドウで開けます。ログインはアプリ内ログインと同じセッションを使います。「閉じる」を押すとプレビューウィンドウだけを終了し、Streamlinkによる録画とコメント取得は継続します。プレビューは視聴ページを別途再生するため、録画とは別に通信量が発生します。録画ファイル自体をリアルタイム再生する機能ではありません。

## 過去配信（タイムシフト）の録画

録画画面の「録画対象」で **過去配信（タイムシフト映像＋コメント）** を選び、視聴URLまたは放送IDを入力して録画を開始します。Streamlinkでアーカイブの先頭（オフセット0）から映像・音声を直接保存すると同時に、視聴ページの番組情報からコメントサーバーへ接続し、NDGRのPrevious / BackwardセグメントAPIで取得可能な過去コメントをJSONLへ保存します。取得コメントは元の投稿時刻を保持し、番組開始時刻を基準としてコメント付き動画へ同期します。コメント取得中も映像録画は継続します。

対象番組がタイムシフト公開中であること、ログイン中アカウントに視聴権限があることが必要です。視聴ページで通常再生できない番組、視聴期限切れ、権限のない番組、コメントAPIの接続情報を取得できない番組ではコメントが取得できない場合があります。その場合も、映像録画は可能な限り継続し、画面に取得失敗理由を表示します。番組やニコニコ側の仕様変更、コメントサーバーの取得上限の影響を受けることがあります。

## コメント取得について

コメント取得にはMITライセンスのNode.jsライブラリ [nicomget](https://github.com/Segu-g/nicomget) を利用します。ニコニコ公式のAPIではなく、配信側の仕様変更により取得できなくなる可能性があります。

録画・保存は、自分が権利を持つ配信または配信者・権利者から許可を得た配信に限って利用してください。保存した映像やコメントを無断で再配布・公開しないでください。ニコニコの利用規約、著作権、肖像権、プライバシーに配慮してください。

Nico Live Message Recorderはニコニコ（ドワンゴ）の公式アプリではありません。
