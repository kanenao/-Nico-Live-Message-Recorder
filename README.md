# Nico Live Message Recorder

ニコニコ生放送の映像ストリームとコメントを別々に直接保存し、コメント付き動画を生成できるWindowsデスクトップアプリです。

**開発版：0.1.0-beta.6**

## 主な機能

- 日本語ダッシュボードとアプリ内バージョン表示
- 放送IDまたは視聴URLを入力してコメント接続
- ニコニコのログイン画面をアプリ内で開く
- 過去コメントとリアルタイムコメントの受信
- コメント、ギフト、エモーション、通知、運営コメントをJSONLへ自動保存
- コメント保存ファイルのCSV書き出し
- コメントJSONLからASS字幕を作成（録画開始時刻に同期）
- 録画動画とコメントログを重ねてニコ生風のスクロールコメント付きWebMを生成
- Streamlinkのニコ生プラグインを利用した配信ストリームの直接録画
- StreamlinkとFFmpegをWindowsアプリに同梱し、別途インストール不要
- 録画停止後にTSからMP4へ無劣化変換
- 画質（最高・低）の選択

**画面キャプチャによる録画機能は廃止しました。** getDisplayMedia、画面・ウィンドウの選択処理は録画には使用しません。

## 必要なソフトウェア

**配布するWindowsアプリの利用者は、Streamlink・FFmpeg・Pythonを別途インストールする必要はありません。** いずれもWindowsアプリの中に同梱されます。

ソースコードから開発・ビルドする場合のみ、Node.js 22以上とWindows PowerShellが必要です。

## 起動とビルド

~~~powershell
npm install
npm start
~~~

Windows向けインストーラーとポータブルZIP（Streamlink・FFmpegを自動取得・検証・同梱）：

~~~powershell
npm test
npm run dist:win
~~~

ビルド成果物は dist フォルダーに作成されます。

## 基本的な使い方

1. アプリ上部の「ニコニコにログイン」からログインします。視聴権限が必要な番組では、視聴可能なアカウントでログインしてください。
2. 放送ID（例：lv123456789）または視聴URLを入力します。
3. 「コメント取得を開始」でコメント保存を始めます。
4. 画質を選び「録画開始」を押します。配信ストリームを直接取得して保存します。録画中にブラウザー画面を開いておく必要はありません。
5. 「録画停止」で配信データの取得を終了します。内蔵FFmpegによりMP4へ無劣化変換します。

## 保存場所

既定の保存先はWindowsの「ビデオ」フォルダー内の NicoLiveRecorder です。

- comments：コメント・イベントのJSONLファイル
- videos：直接取得したTSファイル、または変換後のMP4ファイル

JSONLは1イベント1行で保存します。コメント画面の「CSVを書き出す」から表計算ソフト向けに出力でき、「ASSに変換」から字幕（.ass）を作成できます。「コメント付き動画を生成」では録画動画とJSONLを選択し、コメントが横に流れるWebM動画に合成できます。MP4への変換が有効な環境では、録画開始・停止マーカーを利用してコメントを同期します。ログに ue / shita、色、big / small の指定がある場合は字幕・合成動画にも反映します。

## 直接録画の方式と制限

映像はStreamlinkのニコ生プラグインでHLS配信を取得し、ファイルへ直接書き込みます。Windowsビルド時にStreamlink公式のPortable ZIPを自動ダウンロードし、公開SHA-256と照合したうえでアプリへ同梱します。Portable ZIPにはStreamlink・組み込みPython環境・FFmpegが含まれます。ユーザーのPCのPATHやシステム設定は変更しません。 Streamlink Windows Portable版に含まれる組み込みPython環境とFFmpegは、配布元が独自にビルドした未署名バイナリです。環境によってはセキュリティソフトが誤検知する可能性があります。

Streamlink実行中のみ、アプリ内ログインで得た user_session を一時設定ファイルに渡します。一時設定は録画プロセス終了後に削除し、Streamlinkのプラグインキャッシュも無効にしています。

録画ファイルはまずMPEG-TS（.ts）で保存し、内蔵FFmpegで映像・音声を再エンコードせずMP4へ格納し直します。Streamlinkや配信側の仕様変更、ネットワーク切断、視聴権限、配信形式によって録画できない場合があります。

ログインや視聴権限のない番組、DRM・暗号化などの保護を回避して録画する機能はありません。通常の視聴操作でアクセスできる配信のみを対象にし、利用規約や権利者の許可に従ってください。

## コメント取得について

コメント取得にはMITライセンスのNode.jsライブラリ [nicomget](https://github.com/Segu-g/nicomget) を利用します。ニコニコ公式のAPIではなく、配信側の仕様変更により取得できなくなる可能性があります。

## 利用上の注意

録画・保存は、自分が権利を持つ配信または配信者・権利者から許可を得た配信に限って利用してください。保存した映像やコメントを無断で再配布・公開しないでください。ニコニコの利用規約、著作権、肖像権、プライバシーに配慮してください。

Nico Live Message Recorderはニコニコ（ドワンゴ）の公式アプリではありません。
